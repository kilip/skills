# Skills Repository

This repository contains a collection of specialized skills and automated agents used by Anthonius to enhance productivity and streamline workflows.

## Available Skills

- **project-memory**: Manages short-term and long-term memory for AI agents, allowing for persistent context across sessions.
- **factory**: Spec-driven delivery pipeline (`spec`, `plan`, `execute`, `review`, `finalize`, `run`) that takes a feature from idea to a merge-ready GitHub pull request using isolated-context subagents.

## Usage

These skills are designed to be integrated into development workflows within this environment.
